# Campus Connect

A web portal for college students to connect, join clubs, share resources, and stay updated with campus events and notices.

## Features
- View and post events
- Join clubs and interest groups
- Share notes and links
- Discussion boards for clubs

## Tech Stack
- HTML, CSS, JavaScript (or React)
- Optional backend: Node.js + Express
- Database: MongoDB or Firebase

## Getting Started
1. Fork this repo
2. Clone it to your local machine
3. Open `index.html` in your browser (for static version)
4. If using backend, follow setup in backend folder (if added later)
